 Function: call identical6mer_enrichment.pl to batch process of all the samples.
 Input parameter: list_file is a file contain the sample_Read1.fastq.gz sample_Read2.fastq.gz pos5end_sample_spc_paired.sam of a group of samples. (pos5end_sample.sam was generated by SplitAnalysis.pl)

    Output: Identical_6mer_Enrichment.txt
          The format is as follows:

#Step 2: Identical 6-mer end motif enrichment evaluation

perl Chi_test_identical_6mer.pl Identical_6mer_Enrichment.txt

  Function: perform Chi_test  to compare the counts of identical 6-mer 5′ end motifs between the Same-Strand 5′ Ends fragments and the background set.
  Input parameter: Identical_6mer_Enrichment.txt is the result file from Step 1.
  Output: Enrich_identical_6mer.tsv
          which containing the Chi_test of each sample, and Chi_test of each sample group.



Analysis two: To assess the conservation of identical 6-mer end motifs, the top 40 most frequent motifs and their frequencies within each sample group were extracted.           
          For each target motif, 40 GC-matched background motifs were randomly selected from the corresponding background virtual fragment sets. 
          A permutation test with 10,000 iterations was then performed to compare the purine ratios between the experimental motif set and the aggregated background sets, and the mean difference with its 95% confidence interval was estimated.
